# WaNut

Windows desktop app (C# / .NET 8, WPF) that lets casual players create and run a Minecraft: Java Edition server in a few clicks.

## Rules
- Follow every rule in @./CONVENTIONS.md. It is written in Traditional Chinese; code, identifiers, comments and commit messages are in English.
- Product spec and decisions: @./docs/blueprint.md
- Never add AI co-author lines or AI attribution (Gemini, Claude or other) to commits or PRs.
- Never push directly to `main`; work on a branch and open a PR for Peanut to review.

## Commands
- Build: `dotnet build`
- Test: `dotnet test`
- Format: `dotnet format`
