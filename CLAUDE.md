# WaNut

Windows desktop app (C# / .NET 8, WPF) that lets casual players create and run a Minecraft: Java Edition server in a few clicks.

- Follow every rule in @CONVENTIONS.md.
- Product spec and decisions: @docs/blueprint.md
- Never add AI co-author lines or AI attribution (Claude, Gemini or other) to commits or PRs.
- Never push directly to `main`; work on a branch and open a PR for Peanut to review.
- Build: `dotnet build` · Test: `dotnet test`
