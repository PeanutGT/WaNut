# 美術風格實施步驟書

把 2026-11-15 討論定案的美術方向落到程式裡的順序。方向本身的說明之後放在 `docs/design.md`（步驟 1 產出）；討論紀錄在 `.claude/bee-context.local.md`。

## 原則

- **操作體驗 > 美術表現。** 讓操作變慢、變難懂或讓版面跳動的裝飾不做。
- 每個步驟一個分支、一個 PR，由 Peanut 審查與合併（`docs/CONVENTIONS.md` 第 1 節）。
- 順序是「先便宜、全程式生效的，後昂貴、動結構的」。每一步做完，程式都要能正常發佈。
- 每個 PR 都要通過 `dotnet build`、`dotnet test`、`dotnet format`，並實際開程式在淺色、深色兩個主題下看過。

### 1. 規範正本

- 新增 `docs/design.md`：主軸、配色規則、像素規則、間距、文字、動效、已取消的項目。
- `CLAUDE.md` 的「Reading the spec」加一行指向它。
- `docs/blueprint.md` 和 `Themes/*.xaml` 裡引用的 `design/design-decisions.md` 並不存在，全部改指向 `docs/design.md`。

**完成的樣子：** repo 裡搜尋 `design-decisions.md` 沒有結果；寫新畫面的人只讀 `docs/design.md` 就知道規則。

### 2. 動效共用資源與控制項回饋

- 在 `Themes/` 新增動效資源：俐落的回饋時間、過場時間、緩動曲線；回彈的時間與曲線。之後所有動畫只能引用這些資源。
- `Controls.xaml`：按鈕 hover 與按下、開關、核取方塊、清單項目 hover 與選取，全部加上顏色過渡。
- 硬邊底緣：可按的東西底部 3px 實邊，按下時下移 3px。
- 尊重系統設定：Windows 關閉動畫效果時，過場改成直接切換。

**先決定：** 動效的確切毫秒數與曲線參數；硬邊底緣的顏色（淺、深主題各一）。

**完成的樣子：** 不改任何 View，全程式的按鈕與清單就有回饋；關閉 Windows 動畫效果後沒有任何過場。

### 3. 間距與字級收斂，加自動檢查

- 在 `Themes/` 定義間距資源（3、6、12、18、24、36）與字級樣式。
- 新增一個測試掃描 `src/WaNut.App` 的 XAML，擋下：寫死的顏色、不在尺度內的間距、不在字級表內的 `FontSize`、非 3 倍顯示的像素圖。
- 逐個 View 把現有數值換成資源。現況有 15 種間距、7 種字級，數量多，可以拆成多個 PR；測試先用允許清單放行還沒改的檔案，改完一個移除一個。

**先決定：** 四級字級（提案：12、13、15、21）。

**完成的樣子：** 允許清單是空的，測試在 CI 上擋得住新的違規。

### 4. 分頁與內容切換的過場

- 切換分頁、切換伺服器時，內容淡入加 6–12px 位移。
- 選取指示線滑到新分頁。
- 手感：俐落。

**完成的樣子：** 連續快速切換分頁時不會卡住、不會看到殘影，動畫可以被下一次切換打斷。

### 5. 狀態與訊息的出現

- 橫幅（錯誤、警告、提示）展開出現，不突然把下方內容往下推。
- 狀態徽章換色有過渡。
- 清單項目新增、移除時滑入滑出（玩家、備份、模組）。
- 進度條平滑前進。

**完成的樣子：** 伺服器從停止到上線的整個過程中，畫面上沒有任何元素是瞬間出現或瞬間位移的。

### 6. 新花生與成功時刻的回彈

- 把 `design/art/peanut.py` 產生的 24×24 花生放進 `Assets/`，取代 `peanut-16.png` 的用途。
- `PixelScene` 與所有像素圖一律以 3 倍顯示，移除 32、48、128px 這些不一致的尺寸。
- 加上回彈：伺服器成功上線、長時間工作完成（備份、下載、匯入匯出、模組包安裝）、複製或儲存成功的打勾圖示。只有這些地方可以回彈。

**先決定：** 新花生出現在哪些地方；現有 32×32 場景圖是保留還是換成新造型。

**完成的樣子：** 程式裡只有一種花生、一種像素倍率；回彈只出現在上面列出的時刻。

### 7. 標題圓體

- 打包英文與繁中的開源圓體，用在標題與伺服器名稱；內文維持 Segoe UI 加微軟正黑體。

**先決定（要先查證）：** 候選字型（Nunito、jf open 粉圓）的授權、檔案大小、粗細數量。安裝檔增加太多，或中文只有單一粗細而不夠用時，這一步改成只用系統字並在 `docs/design.md` 記下原因。

**完成的樣子：** 中英文標題在兩個主題下都清楚好讀；安裝檔增加的大小寫在 PR 說明裡。

### 8. 小型確認對話框改成視窗內面板

- 做一個共用的面板容器：遮罩、進出場動畫（俐落）、Esc 與點遮罩關閉、鍵盤焦點留在面板內。
- 依序遷移，一個視窗一個 PR：`ConfirmWindow` → `CloseChoiceWindow` → `DeleteServerWindow` → `ResetWorldWindow` → `BanWindow` → `DuplicateServerWindow`。
- 其餘視窗（建立伺服器、設定、VPS、模組詳情、變更伺服器、匯入匯出世界、還原、初次設定）維持獨立視窗。

**先決定：** 面板的寬度、遮罩顏色、從哪裡進場。

**完成的樣子：** 六個確認流程的行為與原本相同（含鍵盤操作），只是不再跳出新視窗。
