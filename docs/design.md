# WaNut 視覺規範

這份文件是 WaNut 介面外觀的正本。寫新畫面或改既有畫面前先讀這裡；規則改變時先改這份文件，再改程式。實施順序在 `docs/design-rollout.md`。

標「待定」的項目還沒由 Peanut 確認，括號內是目前的提案；確認後把「待定」拿掉。標「（步驟 N）」的規則要等 `docs/design-rollout.md` 的那一步合併後才在程式裡生效。

## 1. 主軸

- **操作體驗 > 美術表現。** 美術服務於操作。讓操作變慢、變難懂或讓版面跳動的裝飾不做。
- **現代介面，像素當點綴。** 控制項與文字維持平滑；像素只出現在花生、場景圖和圖示。
- **記憶點來自滑順。** 「滑順」指每個操作都有回饋、每個變化都有過場，不是指效能或流程步數。
- **有厚度 = 可以按。** 只有可按的東西有硬邊底緣，靜態容器維持平的。

## 2. 配色

- 介面只有米白／暖棕，加上**單一綠色**。綠色只用在三個地方：畫面上唯一的主要按鈕、選取中的分頁、Online 狀態。
- 警告用琥珀色、錯誤用磚紅色，只出現在橫幅與主控台文字。不為裝飾再加其他顏色。
- 淺色主題是暖米白，深色主題是暖棕；預設跟隨 Windows 主題，可在應用程式設定裡改。
- 所有顏色來自 `src/WaNut.App/Themes/Light.xaml` 和 `Dark.xaml` 的筆刷鍵，用 `{DynamicResource ...}` 引用。**XAML 和 C# 裡不寫死色碼。** 新增筆刷鍵時兩個主題檔都要加。
- 圓角一律 6px（`ControlRadius`）。鍵盤焦點框是 2px、`MutedTextBrush`、圓角 8px（`FocusRing`）。

## 3. 像素

- **全程式統一 3 倍：** 圖檔的一格顯示成 3px。禁止非整數縮放，禁止混用倍率。（步驟 6）
- 尺寸：花生 24×24 格 = 72px；場景圖 32×32 格 = 96px；小圖示 16×16 格 = 48px。
- 像素圖一律用 `NearestNeighbor` 縮放，邊緣保持銳利。
- 花生只有一種造型：`design/art/peanut.py` 產生的 24×24 花生，六種表情（待機、眨眼、開心、緊張、愛睏、過熱）。腳本是原始檔，要改圖就改腳本重跑。（步驟 6）
- 花生有表情、不說話。它出現在空白狀態、啟動中／存檔中、成功訊息；不出現在錯誤訊息和進階模式區塊（`docs/blueprint.md` 決策 16）。
- 美術全部原創。不使用 Mojang 的材質檔、Logo 或官方角色，也不做成像官方產品。

## 4. 間距

- 以 3px 為單位，`Margin` 與 `Padding` 只允許 **0、3、6、12、18、24、36**（負值也只能是這些數字）。
- 一個單位 = 一格像素 = 硬邊底緣的厚度 = 圓角的一半，介面和像素畫因此對在同一張格線上。
- 間距直接寫數字，例如 `Margin="0,0,0,12"`；WPF 的四邊間距沒辦法用少數幾個資源組合出來。不在尺度內的數字會被測試擋下。
- 1px、2px 的對齊微調也不允許；需要時改用邊框粗細或對齊方式處理。

## 4b. 自動檢查

`tests/WaNut.Core.Tests/Xaml/DesignRulesTests.cs` 掃描 `Views/*.xaml` 與 `Themes/Controls.xaml`，擋下：寫死的色碼、不在尺度內的 `Margin`／`Padding`、寫成數字的 `FontSize`、不是 48／72／96px 的像素圖。還沒修好的檔案列在測試裡的 `NotYetFixed`，修好一個移除一個；清單只能變短。

## 5. 文字

- 內文字型：Segoe UI，中文明確指定微軟正黑體。
- 標題與伺服器名稱用圓體（步驟 7；待定：候選是 Nunito 與 jf open 粉圓，要先查證授權、檔案大小與粗細數量，不合適就維持系統字並在這裡記下原因）。
- 字級只有四級（待定：數值是提案），定義在 `Themes/Text.xaml`。畫面寫 `FontSize="{StaticResource FontSmall}"`，不寫數字。行高交給字型決定，沒有另外指定。

| 資源 | 字級 | 用途 |
| --- | --- | --- |
| `FontSmall` | 12 | 小標、註解、提示、主控台 |
| `FontBody` | 13 | 內文；每個視窗的預設值 |
| `FontSubheading` | 15 | 分頁、清單項目名稱、小型對話框的訊息 |
| `FontTitle` | 21 | 視窗與頁面標題、伺服器名稱 |

- 介面文字的口吻不變：中性、直白。文字放在 `Strings.resx`（`docs/CONVENTIONS.md` 第 5 節）。

## 6. 動效

- **平時安靜，變化時才動。** 穩定狀態下畫面不動；操作、狀態改變或有工作在進行時才有動作。
- 手感分兩種，所有動畫只能引用 `Themes/` 裡的動效資源，不在 View 裡寫時間或曲線（步驟 2；待定：確切毫秒數與曲線參數）。

| 手感 | 用在哪裡 | 時間 | 曲線 |
| --- | --- | --- | --- |
| 俐落：回饋 | hover、按下、開關、核取、清單選取 | `MotionFeedback`，100ms | `MotionEase`，快速減速，不回彈 |
| 俐落：過場 | 切分頁、切伺服器、橫幅展開、面板進出場 | `MotionTransition`，180ms，位移 6–12px | `MotionEase` |
| 回彈 | 只限下面列出的成功時刻 | `MotionBounce`，320ms | `MotionBounceEase`，超出一點再回到定位 |

- 主題筆刷之間不能直接做顏色動畫，所以狀態顏色是一層疊在上面、淡入淡出的圖層（`Controls.xaml` 的 `ShowHover`、`ShowSelected`、`ShowFill`）。按鈕樣式用 `behaviors:Surface.HoverBrush` 指定 hover 的顏色，不要用觸發器直接換 `Background`。

- **只有這些地方可以回彈：** 花生本身；伺服器成功上線；長時間工作完成（備份、下載、匯入匯出、模組包安裝）；複製或儲存成功的打勾圖示（只有圖示本身回彈）。其餘一律俐落。
- **硬邊底緣：** 可按的東西（按鈕、可點的卡片）底部有 3px 實邊，按下時整顆下移 3px、實邊消失。不模糊、不漸層。顏色是 `ButtonEdgeBrush` 與 `PrimaryButtonEdgeBrush`，按鈕樣式用 `behaviors:Surface.EdgeBrush` 指定。（待定：這兩個筆刷在淺、深主題的色碼）
- 動畫必須可以被下一次操作打斷，不排隊、不留殘影。
- 過場不能突然把其他內容推開；會改變版面的東西（橫幅、清單項目）用展開或滑入出現。
- **尊重系統設定：** Windows 關閉動畫效果時，所有過場改成直接切換（`MotionSettings` 在啟動時把共用時間設成零；執行中才改設定要重開 WaNut 才生效）。視窗失焦或最小化時，循環動畫停止。

## 7. 視窗與面板

- 小型確認流程（一般確認、關閉時的選擇、刪除伺服器、重置世界、封鎖玩家、複製伺服器）顯示成主視窗內的面板：有遮罩、可用 Esc 或點遮罩關閉、鍵盤焦點留在面板內。（步驟 8；待定：寬度、遮罩顏色、進場方向）
- 其餘視窗（建立伺服器、設定、VPS、模組詳情、變更伺服器、匯入匯出世界、還原、初次設定）維持獨立視窗。
