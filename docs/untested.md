# 尚未實際驗證的項目

介面的外觀與手感沒有自動測試。這裡列出已合併或送審、但還沒有人在真的視窗上用滑鼠鍵盤確認過的行為。確認過就把那一行刪掉；發現問題就開 issue 或修正後刪掉。

## 美術風格實施（`docs/design-rollout.md`）

### 步驟 2：動效共用資源與控制項回饋

已確認：程式在淺色、深色主題下正常開啟並顯示硬邊底緣；用離屏視窗確認過 hover、核取、清單選取的圖層會在約 100ms 內淡入淡出，動畫關閉時直接切換。

還沒確認：

- 用真的滑鼠移到按鈕、下拉選單、清單項目、「更多設定」標題上時，hover 顏色有淡入淡出。
- 按住按鈕時整顆下移 3px 蓋住底緣，放開後回到原位；鍵盤按 Space、Enter 時也一樣。
- 按鈕比以前高 3px 之後，各畫面沒有被擠壓或文字被切掉的地方（只看過主視窗空白狀態與初次設定視窗）。
- 側欄伺服器列的「啟動／停止」按鈕在執行中變綠色時，hover 與底緣顏色是綠色系。
- 在 Windows「設定 > 協助工具 > 視覺效果」關閉動畫效果後重開 WaNut，所有顏色變化都是瞬間切換。
- 深色主題的一般按鈕底緣（`#14110D`）在深色背景上是否夠明顯。
- 虛線的「建立伺服器」按鈕、下拉選單和文字輸入框沒有底緣是刻意的，要看實際畫面是否協調。

### 步驟 3：間距與字級收斂

所有畫面的 `Margin`／`Padding` 由腳本換成最接近的尺度值（例如 8→6、10→12、14→12、16→18、20→18、22→24、1→0、2→3），字級換成四級（11→12、14→15、20 和 22→21）。已確認：程式能開啟，主視窗空白狀態與初次設定視窗看起來正常。

還沒確認，每個畫面都要打開看一次：

- 八個分頁（玩家、遊戲設定、伺服器、備份、模組、資料包、連線、效能）與主控台：沒有文字被切掉、沒有元素重疊或擠在一起。
- 所有獨立視窗（建立伺服器、App 設定、VPS、模組詳情、變更伺服器、匯入匯出世界、還原、六個確認視窗）：內容沒有超出視窗、按鈕列對齊。
- 原本靠 1–2px 微調對齊的地方（核取方塊與文字、提示文字的縮排、清單列的圖示）現在是否還對齊。
- 主控台行距變緊（每行上下各少 1px）後是否仍好讀。
- 分頁標題從 14 變 15、標題從 20 或 22 變 21 之後，窄視窗下分頁是否會多換一行。
- 分頁列的選取底線原本蓋住下方的分隔線，現在在分隔線上方 1px。
- 鍵盤焦點框從控制項外 2px 變成 3px，是否會被相鄰元素裁掉。
- 分頁裡的內文跟著分頁標題的字級走，所以從 14 變成 15，比規範的內文 13 大。要決定分頁內文是維持 15 還是改成 13。

### 步驟 4：分頁與內容切換的過場

已確認：用離屏視窗確認過選取指示線會滑到新分頁、滑到一半再切換會從目前位置接著滑、分頁內容淡入；動畫關閉時直接到位。實際程式中指示線出現在選取的分頁下方。

還沒確認：

- 用滑鼠連續快速切換分頁、切換伺服器時不卡、沒有殘影。
- 切換伺服器時，右側整塊內容淡入並上移 6px 的手感。
- 視窗變窄讓分頁換成兩行時，指示線跟著到第二行（設計上跨行時直接跳過去，不滑動）。
- 「玩家（N）」「模組」這類標題文字改變、或分頁出現與消失時，指示線跟著移動。
- 鍵盤用方向鍵切換分頁時指示線也會滑動。

### 步驟 5：狀態與訊息的出現

已確認：用離屏視窗確認過橫幅出現時下方內容是逐步被推開的、進度條往前時滑動而倒退時直接到位；動畫關閉時都是直接切換。實際程式能開啟，狀態徽章在停止狀態下外觀不變。

沒有做：清單項目的滑入滑出（玩家、備份、模組）。這些清單每次更新都是整份清空再重填，直接加動畫會讓每一列在每次重新整理時都動一次；要先把 ViewModel 改成只增減有變動的項目。

還沒確認：

- 啟動一台伺服器，從停止到上線的過程中：狀態徽章的底色淡入淡出（停止 → 啟動中的黃 → 上線的綠），文字顏色是瞬間切換的，看起來是否協調。
- 真的出現錯誤、警告、提示橫幅時（例如伺服器開著時進入遊戲設定分頁、當機說明），橫幅是展開的。
- 切換分頁或切換伺服器時，已經在顯示的橫幅不會重新展開一次。
- 橫幅消失時仍是瞬間消失，下方內容會跳上來。
- 下載 Java 或伺服器檔案、備份時進度條平滑前進；切到下一階段歸零時直接跳回。
- 視窗寬度改變時進度條的填滿比例正確。

### 步驟 8：視窗內面板（共用面板與一般確認）

已確認：用離屏視窗確認過「是」回傳是、「否」／Esc／點遮罩回傳否、開啟時焦點在「否」、關閉後焦點回到原本的輸入框、面板開著時視窗關不掉。實際程式套用新的視窗範本後能正常開啟。

還沒確認：

- 實際觸發一次確認（例如移除模組、刪除備份、在伺服器執行中關閉程式的相關詢問），面板出現在主視窗中央，外觀與進場動畫是否合適。
- 在 App 設定、建立伺服器、VPS 這些較小的視窗裡觸發確認時，面板有沒有被視窗邊界切掉。
- 用 Tab 鍵時焦點只在「是」「否」之間循環，不會跑到遮罩下面的控制項。
- 面板開著時按 Enter、Esc 不會觸發下面視窗的預設按鈕或取消按鈕。
- 螢幕閱讀器會唸出問題內容。
- 主視窗縮到工作列或通知區時出現確認：視窗會被還原並顯示面板。
- 所有視窗改用自訂範本後，標題列顏色、視窗縮放、導覽遮罩是否都和以前一樣。

### 步驟 8：關閉時的選擇

已確認：用離屏視窗確認過焦點在核取方塊時按 Enter 會選「留在通知區」並記住勾選、「停止」回傳停止、Esc 回傳取消。

還沒確認：

- 伺服器執行中按主視窗的 X：面板出現在主視窗裡，三個按鈕的結果和以前一樣（縮到通知區、停止後關閉、取消後視窗留著）。
- 面板開著時再按一次 X 不會出現第二個面板，也不會關掉視窗。
- 勾選「記住」後，下次關閉不再詢問。

### 步驟 6：新花生與成功時刻的回彈

已確認：規則測試確認所有像素圖都是 48、72 或 96px；實際程式的側欄標誌是新的 72px 花生、標題區狀態圖是 96px、玩家與備份分頁的空白狀態圖是 96px；用離屏視窗確認過打勾標示出現時會回彈，動畫關閉時不動。

還沒確認：

- 被拿掉小圖的地方看起來是否空了一塊：建立伺服器的類型清單（原本每一列有類型圖示）、各視窗標題旁、匯入匯出與備份的進度文字旁、更新通知卡、玩家分頁的空清單、伺服器分頁的圖示預留位置、過熱警告。
- 打勾標示取代小花生的地方：備份完成、防火牆正常、VPS 可連線、變更版本完成。
- 伺服器上線的那一刻，標題區的狀態圖回彈一次，而且切換到另一台已上線的伺服器時不會再彈。
- 標題區因為狀態圖變成 96px 而變高，小視窗下是否擠壓到分頁內容。
- 導覽泡泡（96px 的圖）、初次設定視窗（72px 花生）、沒有伺服器時的大圖（從 128 變 96px）、效能分頁的圖。
- 啟動中的大花生（72px）仍會左右搖擺。
- 沒有做：長時間工作完成時的回彈只做在有打勾標示的地方（備份完成、變更版本完成）；下載、匯入匯出、模組包安裝完成時沒有對應的畫面元素可以彈。

### 步驟 8：封鎖玩家

已確認：用離屏視窗確認過在原因欄按 Enter 會取消（和原本一樣，取消是預設）、按「封鎖」會帶回去掉頭尾空白的原因。

還沒確認：

- 在玩家分頁實際封鎖一位玩家：面板出現在主視窗裡，標題、原因欄、按鈕排列是否合適。
- 面板沒有標題列了，原本視窗標題的文字改成面板裡的大標題。
